Integration

集成方式

原生 Node 重写NetToolbox 的 Linux 专有实现（/proc/net、AF_PACKET、ip/iperf3）无法打包进 EXE，故用 Node 原生实现可在 Windows 跑的 13 项能力，零新增依赖。
统一鉴权与审计主动探测类（ping/mtr/fingerprint/ifstat/wol）接 requirePerm('scan')；其余 authRequired；全部 auth.logAction 留痕。
单文件分发经 pkg 打包为 dist/netops-console.exe（~122 MB），含完整工具箱，已实测启动并验证权限门禁。
自检三件套npm run check（13 模板编译 + 重复键扫描）、verify:ui（14 路由 0 控制台报错）、e2e（98/98）。
专属冒烟npm run toolbox — 引擎级 + 接口级鉴权自检，记录于 tools/toolbox-smoke.js。
Node 原生权限接入审计留痕pkg 单文件

网络运维工具箱已并入 netops-console，在界面左侧「网络运维工具箱」导航或访问 /toolbox 即可使用全部能力。
